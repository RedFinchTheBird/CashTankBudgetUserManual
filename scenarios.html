Scenarios and the best plan

Instead of guessing the best retirement age or when to claim Social Security, let the planner try them all. Every time you click Run Plan, the planner runs your plan once for every combination of your choices - each run is a scenario - in both a normal and a down market. You then choose which scenario's results to look at.

What Run Plan tries

  • Retirement ages - retirement ages 1, 2 and 3 of each tax payer, from the Tax Payers page.
  • Social Security claim ages - claim ages 1, 2 and 3 of each tax payer.
  • Roth conversions - none, or each of the Roth buckets (the 22% and 24% brackets). Each bucket is filled every year until RMDs start, as the last step of the year; see how the planner converts.
  • Market - normal and down and flat.

A repeated age counts once, so entering 65, 65, 65 tests only 65. Everything else in the plan stays the same. Milestone dates such as YORTP1 move with each scenario's retirement and claim ages. Running every scenario takes a fraction of a second for a typical plan.

How the best scenario is chosen

  1. Only down-market scenarios are compared, because a plan that survives a bad market will survive a normal one.
  2. The scenario whose money lasts to the latest year wins.
  3. If several last to the end of the plan, the one with the highest net asset value in the final year wins.

The best scenario is marked with a star in the scenario list, but the planner never picks for you: you always choose which scenario to view. See choosing a scenario.

Net asset value is in future dollars Final net asset value is in the dollars of the final year, not today's dollars. Compare scenarios with each other rather than reading the number as today's purchasing power.

Run Plan again after a change

  • Run Plan replaces every scenario with a fresh set. After a run no scenario is selected, so the next time you open Plan Results you choose one.
  • If you change the plan after a run - an age, an amount, an account - Plan Results says the results are out of date until you click Run Plan again.
  • The scenario list and the results you looked at are saved with the project, so you can reopen it and carry on without running the plan again.
Read more than the winner Look at how much the final net asset value changes between neighbouring choices. If claiming at 67 or 70 makes little difference, other things (health, family, peace of mind) can decide.
